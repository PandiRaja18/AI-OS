# Demoing it live

Two scripts: one you rehearse, one for when someone hands you data you have
never seen. The second is the one that actually convinces people.

---

## Before you start

```bash
python -m pip install -e .
python -m pytest -q            # 129 passed
python scripts/start.py demo   # rehearse it once
```

**Use a hosted model when someone is watching.** `ANTHROPIC_API_KEY`, roughly
$0.50 a run, fast and good. A self-hosted 32B takes several minutes per run and
plans worse. Say plainly that the local path exists for data that cannot leave
the building — that is a strength, not an apology.

---

## The five-minute version

```bash
python scripts/start.py demo
```

Narrate against the trace as it scrolls. Four moments matter:

| Trace line | Say this |
|---|---|
| `plan — 4 tasks` | "I gave it a sentence. It wrote the plan, and the plan is validated before anything runs — cycles and unknown dependencies are rejected." |
| `dispatch: t2_live_breaches, t3_last_report` | "Two agents, running at once, because their dependencies resolved together." |
| `conflict_detected … {'t2': '8', 't3': '4'}` | **The one that lands.** "The live data says eight SLA breaches. Last week's status report says four. It noticed." |
| `re-querying t3_last_report` → `conflict_resolved` | "It re-queried the *less confident* source, which found the report was a Monday snapshot taken before four tickets aged out. Payments moves from two to three and now escalates." |
| `signoff_requested` → `memory_promote` | "It stops for a human. Only after approval do those findings become durable facts the next run will recall." |

Then open the report and point at **Open items** — the system saying what it
could not confirm.

If someone asks about failure handling, run the other scenario:

```bash
python scripts/start.py demo --audit
```

That one adds a flaky tool that recovers on retry, an unreachable tool that
degrades the run without failing it, and — with `--outage ledger_lookup` on
`aios run` — a dead tool that forces the planner to route around it.

## The two-minute version, on their data

This is the one worth rehearsing. Someone gives you a folder, or you use your
own.

```bash
aios use ./their-folder        # CSV, Excel, PDF, Word
aios serve                     # http://127.0.0.1:8000
```

`aios use` prints what it found and what the agents can now reach:

```
support is now active
  files:  1 spreadsheet(s), 1 document(s)
  tools:  adhoc_query, describe_schema, doc_search, record_signoff, render_report, sql_query
  tenant: me, reviewer me
```

In the browser: the header shows **`domain: their-folder`**, not `DEMO DATA`.
Submit a goal, watch the trace stream, approve in the review inbox.

**What to say while it runs:** "It has never seen this data. It discovered the
schema itself, and the only questions it can ask the database are ones I
declared — the model never writes SQL against a live system."

---

## Questions you will get

**"Is the data real?"** The demo data is synthetic and generated by the repo.
The engine is not — point at `aios use` on their folder.

**"Did you just hardcode the answers?"** In the demo, the *model's replies* are
recorded so it runs with no key. The tools really execute: that SQL really runs,
those PDFs are really parsed. Show it by changing a row in
`data/support/tickets.csv` and re-running — the numbers change.

**"What happens when it is wrong?"** It is designed to be wrong safely: nothing
reaches durable memory without a human approving it, every figure traces to a
run and a tool call, and the report names what it could not confirm.

**"Could this run on our systems?"** The connectors are the work, not the AI.
A named query per question you want asked, pointed at a read-only credential.

**"How much does it cost?"** About $0.45–0.85 a run on a frontier model, less
with prompt caching. Per-run budgets halt rather than overrun.

---

## If it breaks on stage

- **Model unreachable** — fall back to `python scripts/start.py demo`, which
  needs no model at all. Rehearse this fallback.
- **A run fails on their data** — that is a demo too. The trace shows exactly
  which task failed, how many times it retried, and why it degraded. Most
  systems cannot show you that.
- **Empty plan or odd tasks** — the agent prompts still describe their default
  domain. Say so, and show the `[prompts]` block in the generated pack.
